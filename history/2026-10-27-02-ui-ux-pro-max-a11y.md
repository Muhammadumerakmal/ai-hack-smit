# Accessibility pass with the ui-ux-pro-max skill

- **Date:** 2026-10-27
- **Commits:** see git log
- **Tests:** typecheck and lint clean. Class names only, no logic changes. Dark mode checked in headless Chrome.

## Changes
- Installed the `ui-ux-pro-max` skill globally (`~/.claude/skills/ui-ux-pro-max`, copied from github.com/nextlevelbuilder/ui-ux-pro-max-skill after a review; its tests are left out and the script path is set to `$HOME/.claude/...`). Used its `ux` guidance: contrast at least 4.5:1, WCAG 2.2 target size at least 24 px, visible focus.
- **Light-mode contrast:** readable text in `text-zinc-400` (about 2.6:1 on white) is now `text-zinc-500 dark:text-zinc-400`. This covers dates, "Joined…", "Not set", hints, chat "Try asking" and its footnote, notification times, chart notes and units, the "Workspace" heading and the sign-in divider.
- **Dark-mode contrast:** `text-zinc-500` (about 4.1:1 on zinc-950) gets `dark:text-zinc-400` wherever there was no dark text colour (105 places in 24 files).
- On the always-dark sign-in story panel the feature descriptions go from zinc-500 (about 4:1) to zinc-400.
- Chart axis labels: `fill-zinc-500 dark:fill-zinc-400` at 11 px (were zinc-400 at 10 px). The weekly hours labels and the sidebar heading are 11 px too.

## Checked and fine
